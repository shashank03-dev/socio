# Sociio 🕊️

**Sociio** is a modern, empathetic social anxiety companion application designed to help users navigate social situations with confidence. It provides a serene and supportive environment through beautifully crafted UI and interactive elements.

## ✨ Features

- **Empathy-First Design**: A calming aesthetic built with premium typography and smooth transitions.
- **Interactive Companion**: Engaging animations and micro-interactions to provide a sense of presence.
- **Cross-Platform**: Built for a seamless experience across Mobile, Web, and Desktop.

## 🛠️ Tech Stack

- **Framework**: [Flutter](https://flutter.dev/) (Dart)
- **UI/UX**:
  - **Typography**: [Google Fonts](https://pub.dev/packages/google_fonts) (Outfit, Inter)
  - **Animations**: [Lottie](https://pub.dev/packages/lottie) for high-quality vector animations
  - **Icons**: [Cupertino Icons](https://pub.dev/packages/cupertino_icons) for a sleek, modern look
- **Design Pattern**: Composition-based widget architecture for maximum performance.

## 🚀 Getting Started

To get a local copy of Sociio up and running on your desktop, follow these simple steps.

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.
- A code editor (VS Code, Android Studio, or IntelliJ).
- Git installed.

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/shashank03-dev/socio.git
   cd socio
   ```

2. **Install dependencies:**

   ```bash
   flutter pub get
   ```

3. **Run the application (Linux/Desktop):**
   ```bash
   flutter run -d linux
   ```
   _Note: Ensure you have the [Linux build prerequisites](https://docs.flutter.dev/get-started/install/linux#desktop-development-setup) installed._

## 📂 Project Structure

- `lib/main.dart`: The core application logic and UI.
- `assets/images/`: Visual assets and icons.
- `linux/`, `web/`: Platform-specific configuration and entry points.
