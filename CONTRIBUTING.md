# Contributing to Sociio 🤝

First off, thank you for considering contributing to Sociio! It's people like you that make Sociio such a great tool.

## Code of Conduct

By participating in this project, you agree to abide by our code of conduct. We strive to maintain a welcoming and inclusive environment.

## How Can I Contribute?

### Reporting Bugs

- Use the [GitHub Issue Tracker](https://github.com/shashank03-dev/socio/issues).
- Describe the bug in detail and provide steps to reproduce it.

### Suggesting Enhancements

- Open an issue with the "enhancement" label.
- Explain why this feature would be useful.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue a pull request!

## Style Guide

### Dart Code

- Follow the official [Dart Style Guide](https://dart.dev/guides/language/evolutionary-style).
- Use `flutter format .` before committing.

### Commit Messages

- Use clear and descriptive commit messages.
- Example: `fix: resolve overflow issue in message bubble`

## Local Development Setup

Refer to the `README.md` for platform-specific setup instructions.
